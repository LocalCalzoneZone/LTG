Brief & Lore

Who this hero is in the world, in about 150 words. Every chronicler reads it — the arc writer, the act writer, the interlude planner — and may address the hero by it (the scar, the ring, the accent) but never explain a plot by it. Nothing here is required; a hero with no brief plays exactly as before.
Lore is optional and any length — paste it in. It never generates plot: when the world touches a name in it (a place, a person, an order), at most two paragraphs reach the act writer to colour a line. Headings (# Title) and blank lines split it into paragraphs; that is all the structure it needs.
How this character fights: their style, their weapons, where their magic comes from, what it looks like when it lands, their tells and habits in a brawl. May overlap the lore — this is the text the Generate deck flavour button hands the writer, and later what the fight's narration will draw on. Any length.

Import deck

Paste JSON — an array of cards (or {"cards": [...]}), each with name, type (instant / sorcery / enchantment), mana_cost, effect, and optional flavour (an in-character description of how the effect works — the card editor's Flavour field). Cards are added to the current deck; nothing is replaced. Effect text is run through the translation pass — anything it can't parse is flagged for hand-authoring. See CUSTOM_CARD_SCHEMA.md for the full format.

Update from JSON

Changes found in against the current loadout. The character build and cards come from the new file; this loadout's portrait, animation clips, and clip assignments are kept.

Quit LTG

This quits the Deckbuilder AND the Game — both servers stop (the terminal window closes too), and any connected players are disconnected. Anything not saved with Save is lost.
