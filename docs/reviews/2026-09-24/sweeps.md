### Top 5

1. **A-26 Enemy pricing works on the honour system.** Update 04's core promise is that an enemy's Level is priced from its complexity, but no code checks it. The model reports its own Level, and that number feeds encounter budgets, level-gated removal and gauge credits, so every generated fight's difficulty rests on an unchecked number.
2. **A-07 Narrator.** This is the last unbuilt part of the GDD's architecture. The U24 ledger and chronicles are memory with nothing turning play into prose to feed them.
3. **A-56 Card rewards (with A-06 rarity dial).** Progression is stats only, and a hero's deck never changes over a whole campaign. Because U24 re-reads the deck from the character file on every load, campaign-earned cards need their own instanced layer designed first.
4. **A-01 GDD re-baseline.** The document that claims to be the reference for zero-context readers is wrong in about 17 places (Parry, 40 cards, visible intents, vocabulary, keywords, resolved [OPEN] tags). Every new session or agent has to re-derive the real rules around it.
5. **A-33 Rebalance-register review.** Every number in U04–U10 is still a "playtest starting value". They have only been retuned piecemeal, some only in code (A-34), and with the autoplay harness distrusted there is currently no way to validate them.
